# Bonsai Tracker

A minimal iPhone web app for tracking bonsai trees, pots and care. Data and photos live in the owner's Google Drive.

- Live: https://creamonn.github.io/bonsai-tracker/
- Spec: [docs/SPEC.md](docs/SPEC.md)
- Google setup: [docs/GOOGLE_SETUP.md](docs/GOOGLE_SETUP.md)

## Develop

```bash
npm install
npm run dev
```

Opens at http://localhost:5173/bonsai-tracker/. Pushing to `main` deploys to GitHub Pages.
